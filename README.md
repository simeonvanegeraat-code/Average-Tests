# HumanAverage

HumanAverage is a Dutch-language collection of six transparent browser tests:

- simple visual reaction time;
- four-choice visual reaction time;
- typing speed and accuracy;
- typing consistency across three short rounds;
- a digit-span-like short-term memory task;
- a visual pattern memory task.

The project deliberately avoids fabricated rankings and medical claims. Each result is calculated locally
in the browser, with methodology and primary research sources published alongside the test.

## Local preview

Serve the repository root with any static file server. The production site is hosted by Vercel.

## Publishing checklist

1. Test all tools with keyboard and pointer input.
2. Check desktop and mobile layouts.
3. Validate internal links, structured data, `sitemap.xml` and `robots.txt`.
4. Confirm the privacy page still matches the scripts actually loaded by the site.
5. Do not add advertising code until consent requirements and the privacy policy have been updated.
